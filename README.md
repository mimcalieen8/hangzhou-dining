# 🍽️ Hangzhou Dietary Haven

A sophisticated restaurant finder for Hangzhou, China, specializing in dietary-restricted dining options.

![Screenshot](https://via.placeholder.com/800x400/8B4545/E2CDD2?text=Hangzhou+Dietary+Haven)

## 🌟 Features

- **Interactive Map** - Find restaurants across Hangzhou with an interactive Leaflet map
- **Dietary Filters** - Filter by:
  - Vegan
  - Vegetarian
  - Gluten-Free
  - Oil-Free
  - Allergen-Free
  - Organic
- **Search Functionality** - Search restaurants by name or cuisine
- **Restaurant Cards** - View detailed information with tags, ratings, and descriptions
- **Responsive Design** - Elegant dark pastel red and bone color scheme
- **Real Restaurant Data** - Based on actual Hangzhou restaurants
